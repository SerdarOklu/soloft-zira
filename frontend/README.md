# Frontend

Next.js App Router application. Phase 0 is a placeholder page that proves the package
installs, builds and type-checks. From Phase 1 the interface is built on `@soloft/uds`;
the rules for that are in `../docs/decisions/0002-frontend-nextjs-and-uds.md`.

```bash
npm ci
npm run dev          # http://localhost:3000
npm run build
npm run typecheck
```
